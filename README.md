## 💌 A little celebration, made personal

Birthdays, milestones, or simply *just because* — **Pondy** lets you create a personalized greeting without the hassle. Choose a design, add the perfect words, include a photo if you like, and save a beautiful card to share.

**No account. No ads. No internet required.**

## 🎁 Create your first card

1. Install the signed Pondy APK on an Android phone.
2. Open **Birthday Studio** and pick a card design.
3. Set the recipient's name, sender's name, occasion and message.
4. Change the lettering and optionally add your favorite photo.
5. Select **Save card**, choose where to store the PNG, and share it using your favorite app.

The Android installer may ask permission to install apps from the file manager or browser you used to open the APK. Pondy itself does not request Android permissions.

## 🔒 Privacy-first

Your greeting is yours. Pondy processes chosen photos and card text **on your device**. The Android package contains no internet permission, account system, advertisements, analytics service or location permissions.

- No account or sign-up.
- No advertisements or tracking SDKs.
- No location or contacts access.
- No automatic cloud syncing of your cards.
- Your choice of photo and exported file location.

For details, see [Privacy Information](PRIVACY.md).

## 🧰 Lightweight by design

Pondy uses an offline HTML/CSS/JavaScript card editor packaged into a compact native Android host. Its direct Android build uses Java, D8, AAPT2, zipalign and apksigner — **no Gradle, Android Studio project, or hosted CI build**.

The [full standalone editor](PondWater_Birthday_Studio.html) is available directly from the repository. For the Android compilation and signing process, see [BUILDING.md](BUILDING.md).
