# Pondy — Changelog

## v1.1.0 — October 29, 2026

### Birthday & greeting card editor
- Five colorful built-in card themes.
- Personalized greetings, recipient and sender names.
- Selectable occasions and lettering styles.
- Optional photo backgrounds and PNG image export.
- Portrait-oriented interface designed for Android phones.
- Offline use without accounts or advertising.

### Android release
- Updated adaptive launcher icon with a black background, avoiding white padding on compatible Android launchers.
- Signed Android package retaining the existing application ID and release certificate.
- Direct DEX-based build process — no Gradle and no GitHub Actions.
- No Android permissions declared.

### Verification
- Local browser regression testing and PNG export validation.
- Android manifest, DEX and signature checks.

**Note:** Verification on physical Android hardware remains outstanding.
